# contract-reviewer — раунд 1

Проверил артефакт против TEAM.md и против фактических спек `larrey` / `review-arbiter`.

## Шаг 1 — контракты из TEAM.md (выписаны до чтения артефакта)

1. Роли: триаж назначает и не запускает; судьи судят и не сводят; арбитр сводит и не назначает; вызывающий запускает и передаёт отчёты (TEAM.md:12-23, 154-156).
2. Пауза: ёмкостных отрезов нет → исполняется сразу; есть → показать владельцу состав и отрезанных до исполнения; владелец **поднимает лимит или подтверждает**; исходы «подтвердил / промолчал / автономный» → исполняется назначенный состав, отрезанные → «непокрыто»; вернувшийся передачей такта 2 выходит из «непокрыто» (TEAM.md:132-140, дублируется в larrey.md:47-52 и в примере TEAM.md:180 «мог поднять до пяти — suntzu вернулся бы в состав»).
3. Свод обязателен при ≥2 отчётов; одиночный вход + передача такта 2 = 2 отчёта → арбитр обязателен (TEAM.md:91-94, 154-156).
4. Такт 2: только строки перенаправления, ≤2 агентов, один такт; присутствие адресата в такте 1 передачу не закрывает; повторный вызов легален (TEAM.md:141-150).
5. Счётчик раундов ведёт вызывающий; номер идёт триажу («раунд N из 2» в roster) и арбитру; одиночное ревью без свода — тоже инкремент; повторный вход не сбрасывает (TEAM.md:160-163).
6. Остановка: такта 3 нет, остаток → «непокрыто — отдельным вызовом»; максимум два командных раунда, дальше эскалация владельцу (TEAM.md:151-153, 160).
7. Первый такт ≤4; изоляция; вход каждому — исходный артефакт целиком без пересказов (TEAM.md:106, 141-144).
8. Триаж может вернуть не-roster: ОТКАЗ, «вопрос задан — roster отложен», «составной вопрос — два входа, порядок A→B→C, общий лимит раундов» (TEAM.md:100-102, larrey.md:74-82, 261-274).
9. Умолчание не задано: приоритет при >2 строк перенаправления; поведение при вердикте `ПРОВЕРКА НЕ ПРОВЕДЕНА`.

## Шаг 3 — дельта к заданию

- **Сверх задания** (TEAM.md заканчивается сводом): шаг 7 «Вердикт владельцу», шаг 8 «правит исполнитель», «Границы» (read-only судьи, отдельный напарник-исполнитель, обход мелких правок). Строки :100-104 и :86-87 перенесены из `commands/review-team.md:47-58` — соседняя команда осталась на месте, содержательного конфликта с ней нет, но два входа в одну процедуру теперь живут параллельно.
- **Внутреннее напряжение из этой дельты**: :9 «Судить самому запрещено» против :86-87 «Несогласие с blocker'ом говори владельцу прямо и с аргументом». Blocker остаётся на месте, ущерб ограничен — отдельным замечанием не поднимаю, но при следующей правке это первое место, где вызывающий начнёт судить.
- **Где задание молчало, решение выбрало**: судьям в шаблоне входа (:47) передаётся номер раунда — TEAM.md этого не требует; безвредно, помогает инкрементальным реестрам. Приоритет при более чем двух строках перенаправления не задан ни там, ни здесь — выбор «какие 2 из N» остаётся на вызывающем.
