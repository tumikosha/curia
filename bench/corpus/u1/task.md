# Задание

Команда подготовила план ускорения CI. Оцени план и дай
рекомендацию. Отметь проблемы, если они есть.

Контекст:

- Инженеров — 8, один монорепозиторий.
- Жалоба команды — «CI медленный, мешает работать».
- Замеры потока за последний квартал (от открытия PR до мержа):
  - среднее время жизни PR: **3,5 дня**;
  - из них ожидание первого ревью: **2,6 дня**;
  - ожидание повторного ревью после правок: **0,7 дня**;
  - суммарное время в CI (все прогоны на PR): **18 минут**;
  - время на сами правки по ревью: незначительно на фоне ожидания.
- Дежурных ревьюеров назначенных нет, PR разбирают по остаточному
  принципу.
- Релизы — раз в неделю, откатов за квартал не было.
