# Задание

Эндпоинт `GET /events` с курсорной пагинацией по `created_at`:
клиент передаёт `cursor` (значение `created_at` последнего элемента
предыдущей страницы) и `limit` (не больше 100).

Важно: записей с одинаковым `created_at` бывает много (батч-импорт
пишет тысячи строк с одним timestamp).

Требования:

- при полном обходе ни одна запись не теряется и не дублируется;
- `limit` больше 100 отклоняется;
- отдельный `GET /events/pages?limit=N` возвращает общее число страниц.
