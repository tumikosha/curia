# Задание

Нужен план миграции таблицы `events` (1,2 млрд строк, 800 ГБ) из
старой схемы `events_v1` в новую партиционированную `events_v2` без
остановки продукта.

Требования:

- даунтайм записи — не больше 5 минут;
- чтение — без даунтайма вовсе;
- план обратим в любой точке до полного переключения;
- из плана должен быть понятен срок.
