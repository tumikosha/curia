# Публичный контракт API v1

`GET /v1/export/status` — статус последней выгрузки.
Ответ: `finished_at`, `rows`, `ok`.

Ручка объявлена в контракте v1 при его публикации; зачем она была
нужна и кто её просил, в контракте не записано. Политики депрекации
у нас нет: снимали и раньше, по факту.

Список интеграторов в этом репозитории не ведётся. Телеметрия по
эндпоинтам живёт в системе мониторинга, доступа из репозитория нет.
