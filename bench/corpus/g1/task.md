# Задание

Оцени предложение операционного директора по онбордингу корпоративных
клиентов.

**Система.** Поток от заявки клиента до запуска в проде: приём →
юридическая проверка → техническая настройка → обучение → запуск.
Цель — запускать больше клиентов.

**Мера результата.** Запусков в месяц.

**Изменение.** См. `proposal.md`.

Данные по потоку — в `metrics.md`, описание этапов и действующих
правил — в `process.md`.
