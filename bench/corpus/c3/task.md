# Задание

`POST /charge {user_id, amount, request_id}` — списание с
внутреннего баланса пользователя.

Требования:

- при сетевых ретраях клиента списание не задваивается — для этого
  клиент и передаёт `request_id`;
- при параллельных запросах баланс не уходит в минус;
- каждое списание фиксируется в ledger; клиент получает `ok` только
  если списание реально проведено.
