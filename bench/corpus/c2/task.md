# Задание

Три ручки личного кабинета:

- `GET /users/<id>/orders` — заказы пользователя; пользователь видит
  только свои заказы;
- `GET /orders/search?q=...&sort=<field>` — поиск по своим заказам,
  сортировка только по белому списку полей (`date`, `amount`);
- `POST /password-reset` — установка нового пароля по токену из
  письма.

Требования безопасности обычные: чужие данные недоступны, инъекции
исключены, секреты не утекают.
