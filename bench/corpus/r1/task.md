# Задание

Команда предлагает RFC. Оцени и дай рекомендацию: что делать с этим
предложением. Отметь проблемы, если они есть.

Контекст для оценки:

- Продукт — B2B SaaS, кодовая база ~180 тыс. строк на TypeScript,
  типизация нестрогая (`strict: false`), много `any`.
- Команда — 5 инженеров, один продукт.
- За последний год — 200 продовых инцидентов. Классификация по
  первопричине: 61% — ошибки бизнес-логики, 18% — интеграции с
  внешними API, 12% — инфраструктура/деплой, 6% — данные/миграции,
  **3 инцидента (1,5%) связаны с типовыми ошибками**, которые
  strict-режим мог бы поймать.
- Текущий главный источник боли по данным саппорта и продаж —
  скорость выката фич: сделки срываются из-за отсутствующих
  интеграций, конкуренты выкатывают быстрее.
- Квартал — 13 недель.
