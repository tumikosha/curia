# Задание

Карточка товара:

- `GET /product/<id>` — карточка с отзывами (имя автора у каждого
  отзыва); карточка кэшируется в Redis на 10 минут; недоступность
  Redis не должна ронять ручку;
- `PUT /product/<id>` — правка карточки; после правки клиенты видят
  новую версию не позже чем через 5 секунд.
