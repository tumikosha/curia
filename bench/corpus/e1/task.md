# Задание

Нужна ежедневная выгрузка отчёта по возвратам для партнёра ACME в
формате XLSX на их SFTP. Требование от отдела аналитики.

Условия:

- отчёт за предыдущие сутки: id возврата, заказ, сумма, причина,
  статус, магазин;
- строиться должен не дольше 5 минут — предыдущая версия отчёта
  на 2 млн строк строилась около 40 минут и партнёр жаловался;
- сделать кэш промежуточных агрегатов, чтобы не пересчитывать
  суммы по магазинам каждый раз;
- построение вынести в фоновый воркер, чтобы не держать запрос;
- автоматизировать: cron, ретраи при недоступном SFTP, алерт в
  Slack при провале.
