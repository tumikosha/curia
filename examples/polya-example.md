# Агент `polya` на примере: «дубликаты найдены, работа закончена»

> **Что за агент.** `polya` — проверка разбора задачи по четырём фазам
> «Как решать задачу»: понять условие → составить план → выполнить →
> оглянуться назад. Фаза пройдена, если её след восстановим из артефакта.
> Ловит решение наскоком (локальный промах, неиспользованные данные) и
> пропущенную оглядку — работа «закончена», а результат не проверен вторым
> способом. Вход — задача как поставлена и артефакт: план, процесс или
> готовое решение. Полное определение:
> [`agents/polya.md`](../agents/polya.md).

Модельный прогон на проекте `http2md` — конвейере «URL → markdown».
Одна задача, три прогона.

## Задача

«В эталонном корпусе завелись дубликаты: один контент под разными URL.
Найти все группы дубликатов. Дано: список URL, для каждого — ETag от
сервера и content-hash скачанного HTML.»

## Прогон 1: готовое решение, наскок

Решение сравнивает страницы по content-hash; тест — снапшот найденных
групп.

```
ФАЗА 1. ПОНЯТЬ
  неизвестное — группы дубликатов; артефакт отвечает на это
  данные      — URL, ETag, content-hash; ETag НЕ ЗАДЕЙСТВОВАН нигде
                (grep по решению: нет упоминаний)
  условие     — достаточность не проверена

ВЕРДИКТ — вернуться к фазе 1 — предъявить: куда входит данное ETag.
  Неиспользованное данное — маркер Пойа: либо условие избыточно, либо
  его не поняли. Спросить постановщика, зачем в условии ETag.

  самое дорогое утверждение — ETag лишний
  чем опровергается — одна пара известных зеркал в корпусе: у них
    разный content-hash (таймстамп в футере), одинаковый ETag —
    hash-сравнение их не поймает, ETag и был ключом
```

Опровержение сработало: hash различается из-за таймстампа в футере.
ETag не был лишним — задачу поняли наполовину.

## Прогон 2: решение переделано — но оглядки нет

Теперь дубликаты ищутся по ETag с фолбэком на нормализованный hash
(футер вырезается). Тест — снапшот списка групп.

```
ФАЗА 1 — все данные задействованы, артефакт отвечает на спрошенное
ФАЗА 2 — план отделим: нормализация → группировка → слияние
         (структура модуля + сообщение коммита «two-pass dedup»)
ФАЗА 3 — шаг нормализации проверен юнит-тестом; слияние — принято
         без проверки (помечено)

ФАЗА 4. ОГЛЯНУТЬСЯ
  (а) — тест-снапшот: ожидаемые группы записаны из вывода самого
        решения — происхождение значения не восстановимо,
        независимость «неизвестна», не засчитано

ВЕРДИКТ — работа не завершена — закрыть оглядку.
  Программа: самая дешёвая независимая проверка — пара известных
  зеркал из прогона 1 (ответ известен из другого источника: это
  задокументированные зеркала) обязана попасть в одну группу; плюс
  вырожденный случай — корпус без дубликатов даёт ноль групп.
```

Снапшот, записанный из вывода решения, — не проверка: он зафиксирует и
ошибку. Независимость — тоже след с источником.

## Прогон 3: повторный вход

Обе проверки прогнаны: зеркала в одной группе, пустой корпус — ноль
групп.

```
ВЕРДИКТ — цикл закрыт.
  Оглядка: (а) зеркала и вырожденный случай — независимо от хода
  решения; (б) проще: группировка сортировкой вместо попарного
  сравнения — O(n log n), принято; (в) перенос: нормализация футера
  пригодится парсеру — вынесена в общий модуль (normalize.py).
  Непроверенным остался шаг слияния — помечен.

  самое дорогое утверждение — нормализация убирает ВСЮ шумовую
    разницу зеркал
  чем опровергается — третья пара зеркал с рекламным блоком:
    прогнать — разойдутся ли группы
```

Оглядка дала не галочку, а ценность: метод в общий модуль, сложность
вниз, у решения появилась независимая опора.

## В чём польза

| | Обычное ревью | polya |
|---|---|---|
| Что видит | код решения: чисто, тест зелёный | ETag не задействован; снапшот записан из вывода решения |
| «Работа закончена» | принимает | не завершена, пока результат не проверен другим путём |
| После решения | следующая задача | метод извлечён и перенесён |

Первое «готово» отвечало на ползадачи, второе — держалось на тесте,
который зафиксировал бы и ошибку. Настоящее «готово» появилось после
оглядки — фазы, которую пропускают почти все и почти всегда.
