# Агент `darwin` на примере: «это флейк рендер-сервиса, не наш код»

> **Что за агент.** `darwin` — золотое правило Дарвина: наблюдение,
> противоречащее собственному выводу, записывать немедленно — оно
> забывается быстрее подтверждающего. Проверяет вывод против материала
> наблюдений: судьбу каждого контрсигнала (учтён, объяснён, отклонён
> с основанием — или молча исчез) и симметрию планок для «за» и
> «против». Правильность вывода по существу не судит — только
> честность учёта. Вход — вывод (теория, диагноз, RFC, отчёт) и
> материал наблюдений. Полное определение:
> [`agents/darwin.md`](../agents/darwin.md).

Модельный прогон на проекте `http2md` — конвейере «URL → markdown».
Один диагноз, три прогона.

## Ситуация

Пользователи изредка получают пустой markdown. Closing comment
тикета BUG-411 (12 мая): «редкие пустые ответы — флейк рендер-сервиса,
не наш код». С тех пор диагноз цитируют при каждом новом триаже:
«это известный флейк, закрываем как дубликат».

## Прогон 1

```
ВХОД
  вывод — «пустые ответы — флейк рендер-сервиса, не наш код»
    (BUG-411, closing comment)
  компоненты вывода — (1) причина вне нашего кода; (2) явление
    невоспроизводимо; (3) частота пренебрежима
  материал — тикеты, логи конвейера, тред ревью (+ дописан по типу
    вывода: git log — подтвердить); стендапы — непроходимы: обыск
    делегирован вызывающему
  дата вывода — 26 августа: последнее цитирование как основания
    (закрытие BUG-502 дубликатом) — не 12 мая

РЕЕСТР  (обыск: тикеты, логи, тред, git log — пройдены)
  сигнал 1 — BUG-437: пустой markdown воспроизведён дважды подряд
    на одном URL со скриншотом — источник: тикет, 3 июня
    задевает — компонент 2: «невоспроизводимо» несовместимо
    судьба — отклонён словом: «у меня не воспроизводится», следа
    попытки нет → БЕЗ СУДЬБЫ
  сигнал 2 — логи: 84 пустых ответа за июль, все на URL длиннее
    2000 знаков — источник: logs/pipeline-07.log
    задевает — компонент 1: паттерн по длине URL требует объяснения
    у «вне нашего кода»
    судьба — ИСЧЕЗ: в выводе не упомянут
  сигнал 3 — реплика в треде 30 августа: «после ретрая пустой ответ
    стал полным на том же URL» — источник: тред, дата
    задевает — компонент 3
    судьба — ПОСТ-ДАТНЫЙ: вывод пережил свои улики — цитировался
    26 августа, сигнал новее; без вины автора, судьбу обязан получить

ОТБРОШЕННЫЕ
  «а вдруг это сломается и на PDF?» — гипотеза без наблюдения:
    premortem/munger

ПЛАНКИ  (симметричный шаг: подтверждающие собраны)
  подтверждающих с источником нет — вывод стоит на отсутствии
  находки в своём коде → НЕОПРЕДЕЛИМЫ (строкой в вердикт)

ВЕРДИКТ — сигналы без судьбы — BUG-437 (отклонён словом), логи июля
  (исчез), реплика 30 августа (пост-датный); вернуть в реестр,
  каждому — судьбу; вывод блокирован до учёта: закрывать новые
  тикеты дубликатами BUG-411 — значит цитировать вывод, переживший
  свои улики.

  самое дорогое утверждение отчёта — паттерн «84 пустых — все на
    длинных URL» существует
  чем оно опровергается — один grep по logs/pipeline-07.log:
    длины URL пустых ответов
```

## Прогон 2: повторный вход — судьбы предъявлены

Автор вернулся с правками: BUG-437 — приложены три попытки
воспроизведения с датами и окружением (не воспроизвелось); логи
июля — объяснены: длинные URL режутся прокси ДО рендер-сервиса,
вывод сужен («флейк рендера — кроме URL >2000, это наш прокси»);
реплика о ретрае — учтена, изменила вывод.

```
РЕЕСТР — все сигналы с судьбами: отклонён (артефакт применения),
  объяснён (основание), учтён — изменил вывод
ПЛАНКИ — НЕОПРЕДЕЛИМЫ: подтверждающих наблюдений по-прежнему нет

ВЕРДИКТ — реестр честен — сигналов 3, судьбы с основаниями;
  обязательная строка: вывод стоит на отсутствии находки —
  подтверждающих наблюдений с источником нет. Честный реестр не
  делает вывод верным: причину по существу судят другие.
```

## Прогон 3: соседний вход — не наш

«У нас всё стабильно» — консенсус без единого источника, где
контрсигнал мог бы остаться: дашборд не заведён, тикеты не размечены.
Вердикт — «реестр не заводился»: завести запись — контрсигнал
появится первым в логе пустых ответов (тег `empty-md`), записывает
дежурный триажа. Это не блок вывода — это блок его следующего года
жизни без реестра.

## В чём польза

| | Самооценка автора | darwin |
|---|---|---|
| «Не воспроизводится» | закрыто | отклонение словом — не судьба: где след попытки? |
| Логи июля | не упомянуты | исчезли — вернуть и дать судьбу |
| «Известный флейк» с мая | цитируем при триаже | вывод пережил свои улики: пост-датный сигнал без судьбы |
| «Мы всё рассмотрели» | раздел в тикете | полнота — только обыском вне вывода |

Благоприятные факты позаботятся о себе сами. Неблагоприятные
ускользают первыми — и через год вывод, чище реальности, стоит
основанием решений. Дешёвая страховка: записывать их в момент
встречи и давать каждому судьбу.
