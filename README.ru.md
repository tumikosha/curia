# Curia

*English version: [README.en.md](README.en.md).*

Мыслительная техника — повторяемая процедура разбора, которая не
зависит от озарения. Её изобретают люди, вынужденные решать под
неопределённостью и заметившие, что ум по умолчанию ошибается
одинаково: четыре правила Декарта, эвристики Пойа, моральная алгебра
Франклина, оценка Ферми, ТРИЗ Альтшуллера, расчёт Сунь-цзы до похода,
пять «почему» Оно, петля OODA Бойда, забор Честертона, теория
ограничений Голдратта. Каждая техника мала, названа и ловит один класс
ошибки — тот, который без неё не виден, потому что выглядит как
здравый смысл.

Модели такая процедура нужна больше, чем человеку. На просьбу
«отревьюй» модель выдаёт правдоподобное общее мнение: оно почти всегда
звучит разумно и почти никогда не проверяемо. Техника задаёт, куда
смотреть и что считать дефектом, — и ответ становится опровержимым:
видно, какой шаг пропущен, на каком основании сделан вывод и что
должно оказаться правдой, чтобы вывод устоял. Проверяемый ответ
полезнее убедительного.

**Curia** (лат. «судебный двор») — каталог из 21 ревью-агента для
Claude Code и совместимых harness: девятнадцать судей, каждый с одним
вопросом, триаж и свод. Всё определено в markdown — агенты переносимы
в любой harness, где промпт читается как текст.

Идея: вместо одного «универсального ревьюера» — коллегия узких судей.
Каждый агент воплощает одну проверенную мыслительную процедуру
(пятишаговка Маска, забор Честертона, оценка Ферми, петля OODA…) и
отвечает ровно на один вопрос. Состав под конкретный вход назначает
триаж, отчёты сводит арбитр — до человека доходит один вердикт.

## Как это работает

1. **Триаж.** [`larrey`](agents.ru/larrey.md) по входу определяет фазу
   работы и назначает минимальный состав (первый такт ≤4 судей),
   порядок и вход каждому. Сам не судит.
2. **Такты.** Назначенные судьи работают параллельно и изолированно —
   никто не видит чужих отчётов до сдачи своего. Максимум два такта.
3. **Свод.** [`review-arbiter`](agents.ru/review-arbiter.md) отсеивает
   недоказанное, разрешает конфликты и выносит единственный вердикт;
   несудившееся честно помечается «непокрыто».

Полный протокол — [TEAM.md](TEAM.md).

## Фазы и составы

Фазу определяет `larrey`: по вопросу вызывающего, а если вопрос не
задан — по состоянию работы. У каждой фазы свой **стартовый состав**;
это дефолт на случай, когда в артефакте нет ничего специфичного.

| фаза | вопрос вызывающего | база фазы | порядок отреза |
|---|---|---|---|
| **A** — до старта | «делать ли, выиграем ли, не умрём ли» | [`hamming`](agents.ru/hamming.md) + [`suntzu`](agents.ru/suntzu.md) + [`munger`](agents.ru/munger.md) | `suntzu` → `hamming` → `munger` |
| **B** — в работе | «как разобрать, туда ли копаем» | [`descartes`](agents.ru/descartes.md) + [`polya`](agents.ru/polya.md) | `polya` → `descartes` |
| **C** — готовое | «сделано — проверь» | [`contract-reviewer`](agents.ru/contract-reviewer.md) + [`adversarial`](agents.ru/adversarial.md) | `adversarial` → `contract-reviewer` |

Поверх базы состав добирается по **приметам входа**. Приметы фазе не
подчинены: числовое обещание тянет `fermi` и в плане, и в готовой
работе. Строки отранжированы по профильности — при ёмкостном отрезе
нижние режутся первыми.

| примета во входе | добирается | его вопрос |
|---|---|---|
| числовое обещание, лимит | [`fermi`](agents.ru/fermi.md) | сходится ли арифметика |
| предстоящий необратимый шаг, скорость решения | [`bezos`](agents.ru/bezos.md) | какая дверь и соразмерен ли процесс |
| инцидент, RCA, фикс | [`ohno`](agents.ru/ohno.md) | докопан ли корень, стоит ли на месте |
| вывод + материал наблюдений | [`darwin`](agents.ru/darwin.md) | где записано противоречащее |
| удаления | [`chesterton`](agents.ru/chesterton.md) | понята ли причина ограды |
| оптимизация с мерой | [`goldratt`](agents.ru/goldratt.md) | в ограничение ли работа |
| компромисс, боль без решения | [`altshuller`](agents.ru/altshuller.md) | разрешено ли противоречие |
| повторяющийся цикл, темп | [`boyd`](agents.ru/boyd.md) | замкнута ли петля, короче ли темпа |
| бинарная развилка с доводами | [`franklin`](agents.ru/franklin.md) | что останется после вычёркивания |
| длинное или неоднозначное ТЗ у готового | [`reverse-spec-reviewer`](agents.ru/reverse-spec-reviewer.md) | какое ТЗ решает артефакт |
| готовое перед необратимым применением: миграция данных, прод-конфиг, деплой без отката | [`premortem-reviewer`](agents.ru/premortem-reviewer.md) | как это провалилось |
| просьба упростить или сократить; требование без названного источника | [`elon`](agents.ru/elon.md) | оспорить, удалить, упростить |

Три правила поверх таблиц:

- **Первый такт — не больше четырёх.** Стало больше — режется сначала
  база по своему порядку, затем приметные снизу вверх. Каждый
  вырезанный назван поимённо с причиной, и его вопрос уходит в
  «непокрыто» свода: молча пропавший — дыра, отрезанный с причиной —
  решение.
- **Носитель вопроса не режется никогда.** Носитель — тот, с чьей
  юрисдикцией совпал вопрос вызывающего; вопрос не задан — последний
  базовый в порядке отреза (A — `munger`, B — `descartes`,
  C — `contract-reviewer`).
- **Замещение.** Вход — постмортем, и сверять его не с чем:
  `contract-reviewer` выбывает, его место занимают `ohno` и `darwin`.

## Команды

- [`/curia`](commands/curia.md) — собрать команду ревью под конкретный

- [`/review`](commands/review.md) — прогнать готовую работу через цикл

## Агенты

Все агенты read-only: читают артефакт, ничего не меняют.

### До старта — «делать ли?»

**[`hamming`](agents.ru/hamming.md) — Ричард Хэмминг, «You and Your
Research».** Спрашивает, какие важные задачи есть в области, над какой
из них эта работа и, если ни над какой, почему. Важность проверяется
тремя признаками: есть ли способ атаки, даёт ли результат сложный
процент, меняет ли он что-то для области. Ловит хорошо сделанную
неважную работу и портфель безопасных мелочей за период.

**[`suntzu`](agents.ru/suntzu.md) — Сунь-цзы, «Искусство войны».**
Считает исход до выступления по пяти факторам и семи сопоставлениям:
согласие целей, время, местность, полководец, метод. Выносит go/no-go —
выступать, не выступать или сначала разведка, — и «не выступать» здесь
законный результат, а не отказ работать. Ловит походы, проигранные до
старта, и выступление вслепую, когда исход решают неизвестные, молча
засчитанные в свою пользу.

**[`munger`](agents.ru/munger.md) — Чарли Мангер и Карл Густав Якоби.**
Инверсия: вместо «как добиться успеха» — «как гарантированно это
провалить», и затем сверка полученного списка убийц с тем, что
делается. Убийца засчитывается только с механизмом гарантии — цепочкой,
которая делает критерий успеха недостижимым; вероятностные сценарии —
жанр премортема. Ловит полировку пути к успеху при открытом пути к
смерти.

**[`fermi`](agents.ru/fermi.md) — Энрико Ферми.** Оценка порядка
величины до начала работы: обещание плана раскладывается на 3–7
факторов, каждый оценивается вилкой с основанием, границы сворачиваются
и сравниваются с бюджетом. Дёшево убивает проекты, у которых не
сходится арифметика. Ловит числа, которые никто не перемножал, и ложную
точность — «4,5 дня» там, где факторы известны с точностью до порядка.

**[`bezos`](agents.ru/bezos.md) — Джефф Безос.** Классифицирует решение
до выбора скорости: дверь двусторонняя (обратимая) или односторонняя, и
соразмерен ли процесс принятия типу двери. Обратимость доказывается
механизмом отката, а не словом «откатим». Ловит месячное обсуждение
того, что откатывается за час, необратимое на бегу и ложную
двусторонность. Фирменный ход — сузить необратимое дизайном: флаг,
canary, бэкап.

**[`franklin`](agents.ru/franklin.md) — Бенджамин Франклин, письмо
Пристли 1772 года.** Моральная алгебра: два столбца доводов, и вместо
подсчёта — вычёркивание равновесного; что осталось, то и решает.
Суждения веса бывают двух видов, эквивалентность и доминирование, оба
проверяемы и подтверждаются решающим — веса агент не выдумывает. Ловит
счёт вместо веса, когда толпа лёгких доводов побеждает один тяжёлый.

**[`elon`](agents.ru/elon.md) — Илон Маск.** Пятишаговка в жёстком
порядке: оспорить требование, удалить, упростить, ускорить,
автоматизировать. Порядок и есть метод: ускорять и автоматизировать то,
что следовало удалить, — работа, закрепляющая лишний шаг. Ловит
идеальные ответы на неправильный вопрос и оптимизацию того, чего не
должно существовать.

### В работе — «туда ли копаем?»

**[`descartes`](agents.ru/descartes.md) — Рене Декарт, «Рассуждение о
методе».** Четыре правила: ничего не принимать на веру без пометки,
делить трудность на части, идти от простого к сложному, делать перечни
полными. Ловит несущую предпосылку без статуса — здание стоит на
непроверенном, и по нему этого не видно — и дырявый перечень: «кажется,
все случаи» без доказательства полноты.

**[`polya`](agents.ru/polya.md) — Дьёрдь Пойа, «Как решать задачу».**
Четыре фазы: понять условие, составить план, выполнить, оглянуться
назад. Фаза считается пройденной, если её след восстановим из
артефакта. Ловит решение наскоком — локальный промах мимо спрошенного,
неиспользованные данные — и пропущенную оглядку, когда работа
«закончена», а результат не проверен вторым способом и метод не
извлечён.

**[`boyd`](agents.ru/boyd.md) — Джон Бойд, петля OODA.** Наблюдение,
ориентация, решение, действие: замкнута ли петля — возвращается ли
каждое действие наблюдением результата — и короче ли цикл темпа среды.
Выигрывает не лучшее решение, а более короткий цикл. Ловит полировку
решения при цикле длиннее темпа среды, разорванную петлю и замёрзшую
ориентацию — картину мира, которую наблюдения больше не меняют.

**[`goldratt`](agents.ru/goldratt.md) — Элияху Голдратт, теория
ограничений.** Пять шагов фокусировки: найти ограничение системы,
выжать из него максимум, подчинить ему всё остальное, расширить,
вернуться к шагу 1. Ловит локальное улучшение вне узкого места — оно не
меняет пропускной способности системы — и добавление ресурсов в обход
выжимания того, что уже есть.

**[`altshuller`](agents.ru/altshuller.md) — Генрих Альтшуллер, ТРИЗ.**
Ядро АРИЗ: функция вместо механизма, идеальный конечный результат
(функция выполняется, механизма нет), противоречие «улучшая A, ухудшаем
B» и его разрешение разделением по координате — во времени, в
пространстве, по условию, между системой и частями. Ловит компромисс
вместо разрешения, когда критерий куплен, а конфликт жив, и симптомное
решение без сформулированного противоречия.

### Готовое — «сделано — проверь»

**[`contract-reviewer`](agents.ru/contract-reviewer.md) — сверка с
заданием через восстановленные контракты.** Читает готовый артефакт —
код, схему, документ — и независимо восстанавливает контракты и
инварианты, которые тот обязан держать, и лишь затем сверяет с исходным
заданием. Вызывается после исполнителя и до того, как результат уйдёт
человеку.

**[`adversarial`](agents.ru/adversarial.md) — независимый adversarial
review.** Рассматривает чужое решение не как объяснение, которому нужно
верить, а как гипотезу, и пытается её опровергнуть: скрытые
предположения, пропущенные ограничения, места, где решение работает
случайно, минимальный контрпример. Особенно полезен там, где решение
выглядит очевидно правильным, — именно там сидят неявные предположения.

**[`reverse-spec-reviewer`](agents.ru/reverse-spec-reviewer.md) —
обратное восстановление ТЗ.** По одному лишь готовому артефакту
восстанавливает, какое задание он решает, и только потом сравнивает с
настоящим. Ловит подмену задачи — случай, когда работа сделана
качественно, но не та. Нужен там, где ТЗ длинное или неоднозначное.

**[`premortem-reviewer`](agents.ru/premortem-reviewer.md) — пре-мортем
Гэри Клайна.** Предполагает, что решение уже провалилось, и
восстанавливает механизмы провала — не «что может пойти не так», а «вот
как именно это уже случилось». Вызывается на рискованных и необратимых
изменениях в дополнение к `contract-reviewer`.

**[`chesterton`](agents.ru/chesterton.md) — Гилберт Кит Честертон,
ограда в чистом поле.** Для каждого предлагаемого удаления ищет автора,
исходные причины и тех, кто на ограду успел опереться; снос с непонятой
причиной блокируется до выяснения. Пара-антагонист `elon`: его шаг 2
предлагает удаления, `chesterton` отвечает на графу «вернуть». Ловит и
обратное — поклонение ограде, у которой живой причины уже нет.

**[`ohno`](agents.ru/ohno.md) — Тайити Оно, Toyota Production System.**
Пять «почему» и genchi genbutsu — «иди и посмотри сам». Проверяет,
доходит ли цепочка причин до корня, устранение которого убирает класс
повторений, и стоит ли каждое звено на увиденном на месте, а не на
пересказе. Ловит фикс симптома, цепочку, оборванную на «инженер
ошибся» — за ошибкой человека стоит процесс, который её допустил, — и
звено из предположения: лог не открывали, код не читали.

**[`darwin`](agents.ru/darwin.md) — Чарльз Дарвин, золотое правило.**
Наблюдение, противоречащее собственному выводу, записывать немедленно,
потому что оно забывается быстрее подтверждающего. Проверяет судьбу
каждого контрсигнала — записан, объяснён, отклонён с основанием или
молча исчез — и симметрию планок для «за» и «против». Правильность
вывода по существу не судит, только честность учёта.

### Служебные

**[`larrey`](agents.ru/larrey.md) — Доминик Жан Ларрей, хирург
Наполеона.** Изобретатель сортировки раненых по срочности и профилю
раны, а не по чину. Триаж ревью: не судит артефакт и не запускает
агентов, а назначает — минимальный состав (первый такт ≤4), порядок,
вход каждому и свод через `review-arbiter`; исполняет вызывающий. Ловит
«все на всё», «не того специалиста» и «хор без свода».

**[`review-arbiter`](agents.ru/review-arbiter.md) — свод отчётов в один
вердикт.** Сводит отчёты нескольких ревьюеров в один список замечаний:
отсеивает недоказанное, схлопывает дубли, разрешает противоречия и
выносит единственный вердикт. Несудившееся честно помечает
«непокрыто». Вызывается после того, как отработали два или более
ревьюера.

## Структура репозитория

- [`commands/`](commands/) — слэш-команды, исполняющие протокол.

  посевном корпусе.

## Портируемость

Агент — это markdown-файл с одной процедурой; harness-специфичен
только frontmatter. В harness без субагентов roster исполняется
последовательными одиночными вызовами со свежей сессией на каждого
ревьюера (изоляция), свод — последним вызовом `review-arbiter` со
всеми отчётами во входе. Подробности — в конце [TEAM.md](TEAM.md).

## Установка

Нужен Claude Code или совместимый harness. Агенты и команды — обычные
markdown-файлы; установка сводится к тому, чтобы harness их увидел.

**Выбери один язык.** В `agents/` лежат английские определения, в
`agents.ru/` — русские. У парных файлов одинаковое поле `name:`,
поэтому поставить обе папки сразу нельзя: два файла заявят одного и
того же агента.

```sh
git clone https://github.com/tumikosha/curia.git ~/src/curia

CURIA=~/src/curia
AGENTS=agents            # agents — английские, agents.ru — русские

mkdir -p ~/.claude/agents ~/.claude/commands
ln -sfn "$CURIA/$AGENTS"/*.md  ~/.claude/agents/
ln -sfn "$CURIA/commands"/*.md ~/.claude/commands/
```

Симлинки, а не копии: `git pull` обновляет определения без
переустановки. Если живая связь с клоном не нужна, замени `ln -sfn` на
`cp`. Повторный запуск безопасен — ссылки перезаписываются.

Проверка: 21 агент, три команды, битых ссылок нет.

```sh
ls ~/.claude/agents/*.md | wc -l
for f in ~/.claude/agents/*.md ~/.claude/commands/*.md; do
  [ -e "$f" ] || echo "битая ссылка: $f"
done
```

Поставить в один проект, а не глобально — те же команды с `.claude/`
вместо `~/.claude/` в корне проекта.

Удаление снимает только ссылки на клон, чужие файлы в `~/.claude/` не
трогает:

```sh
for f in ~/.claude/agents/*.md ~/.claude/commands/*.md; do
  case "$(readlink "$f")" in "$CURIA"/*) rm "$f";; esac
done
```

## Примеры вызова

**Идея или план до старта, и непонятно, кого звать.** Общий вход:
триаж сам определит фазу работы и назначит состав.

```
/curia хотим переписать парсер на Rust: в 5 раз быстрее, питоновский
код выбросим, месяц работы. Стоит ли делать?
```

Фаза A. `hamming` — носитель вопроса «стоит ли», `munger` — база фазы,
`fermi` по триггеру «в 5 раз» и «месяц», `chesterton` по триггеру
«выбросим код». `suntzu` срезан по ёмкости — состав ограничен
четырьмя. Свод у арбитра.

**Готовый дифф или PR.** Цикл ревью с изоляцией контекста:

```
/review ветка feature/oauth-refresh против тикета PROJ-412
```

Параллельно `contract-reviewer` и `premortem-reviewer`; при длинном
или неоднозначном ТЗ добавляется `reverse-spec-reviewer` в два хода.
Вердикт арбитра показывается дословно, без смягчения: если вернулось
«ВЕРНУТЬ АВТОРУ», блокеры перечисляются как есть.

**Длинная работа, ревью параллельно с исполнителем.** Ревьюеры живут
рядом и получают куски по мере готовности, а не всё в конце:

```
/review-team миграция биллинга на новую схему
```

**Профильный вопрос очевиден — зови судью напрямую.** Триаж нужен,
когда не знаешь, кого звать; когда знаешь — это лишний такт:

```
Прогони fermi по этому плану: 4,5 дня на индексацию 10 млн страниц.
```

```
Ночью упал воркер по OOM, подняли лимит с 2 до 4 ГБ, постмортем
закрыт. Прогони ohno.
```

```
Собираюсь удалить поддержку legacy-конфига и код вокруг неё.
Прогони chesterton по списку удалений.
```

**Решение, а не код.** Судьям фазы A артефакт не нужен, они работают
с намерением:

```
/curia выключаем поддержку старого API в следующем релизе — какая
это дверь?
```

Вопрос лежит в юрисдикции `bezos`, но во входе есть триггер:
выключение — это удаление, на которое кто-то мог опереться, поэтому
триаж добавит `chesterton`.

Разборы работы агентов на живых входах — в [`examples/`](examples/).
